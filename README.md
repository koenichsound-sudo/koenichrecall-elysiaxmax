# koenichrecall-elysiaxmax
Koenich Recall – elysia xMax ist ein VST3-Plugin für macOS Apple Silicon. Es speichert Hardware-Einstellungen mit 12 Drehreglern und 3 Tastern direkt im REAPER-Projekt. Mit originalgetreuer Frontplatte, präziser Werteingabe und automatischem Recall. Keine Audioverarbeitung – das Signal bleibt unverändert. Entwickelt mit JUCE/C++.
